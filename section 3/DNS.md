1. DNS 
DNS -- domain name system
DNS ek system hai jo domain name ka uss corresponding IP address se find/match karne mai help kartai

google.com --> DNS -- > google ka ip address --> google server


2. DNS ka jarurat kyu hai
human ke lye google.com yaad karna easy hai but 142.xxx.xxx.xxx yeh hard hai , eisiya we use Domain and DNS background mai ip adress find kartai 


DNS resolver kya hai
yeh ek service/ system hai jo dns ka requered ip address ko find karne mai help kartai 

basically ham google.com likhtai  dns resover hamko uska ip datai



DNS cache kya hai
DNS cache bascially bar bar same ip ko find karna unnecessary hotai so uske bachne ke lye DNS cache use hotai

cache -- temporarily saved information, taki next time same information faster mil sake

first time 
Domain --> DNS lookup --> IP

later 
Domain --> cached information --> IP
